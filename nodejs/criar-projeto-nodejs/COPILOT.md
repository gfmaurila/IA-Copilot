# COPILOT

Fluxo obrigatório:

1. Leia `CRIAR-PROJETO.md`.
2. Leia `tasks/rules/`.
3. Leia a Spec solicitada.
4. Leia somente as Skills necessárias.
5. Implemente seguindo padrões Node.js/TypeScript.
6. Execute:
   - npm install ou pnpm install conforme o projeto
   - prisma migrate
   - prisma generate
   - testes
   - build backend
   - build frontend
7. Corrija erros.
8. Só então arquive a Spec.

Não introduza padrões de C# ou Java sem necessidade.

Prefira padrões idiomáticos de Node.js.
