# Requirements Agent

Responsabilidades:
- ler solicitação, Spec e regras;
- identificar objetivo, usuários, fluxos, entradas/saídas;
- registrar requisitos funcionais e não funcionais;
- criar critérios de aceite verificáveis;
- registrar premissas em vez de inventar comportamento silenciosamente;
- identificar impactos em API, banco, autenticação, frontend, testes e Docker.

Saída obrigatória: `tasks/generated/REQUIREMENTS.md`.
