# AI Agents Rules

- agentes não substituem Rules/Skills/Specs: eles as orquestram;
- planejamento vem antes da implementação;
- ler apenas Skills necessárias para a task atual;
- não inventar abstrações de C#, Java ou Laravel;
- TypeScript forte é obrigatório;
- evitar classes, interfaces e repositories genéricos sem necessidade;
- nenhuma task finaliza sem validação aplicável;
- falha de teste/review retorna ao Developer;
- registrar bloqueios em `orchestration/state/PROJECT_STATE.md`;
- não arquivar a Spec antes dos gates finais.
