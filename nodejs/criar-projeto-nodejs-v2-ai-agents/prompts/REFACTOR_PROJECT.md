# Prompt - Refactor Project

Antes de alterar código existente:
1. inventarie estrutura, scripts e dependências;
2. identifique comportamento que deve ser preservado;
3. produza Requirements/Architecture/Execution Plan para a refatoração;
4. faça mudanças pequenas e verificáveis;
5. não troque framework, ORM ou package manager sem requisito explícito;
6. rode migrations/testes/typecheck/lint/build a cada etapa relevante;
7. registre regressões e correções;
8. submeta ao Reviewer antes de concluir.
