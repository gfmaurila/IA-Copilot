# Prompt - Create Project

Crie o projeto usando este template como contrato operacional.

Ordem obrigatória:
1. leia `CRIAR-PROJETO.md`;
2. leia `AGENTS.md`;
3. leia `tasks/rules/`;
4. leia a Spec ativa;
5. gere Requirements, Architecture Plan e Execution Plan;
6. leia somente as Skills necessárias para a task atual;
7. implemente incrementalmente;
8. execute migrations, testes, typecheck/lint e builds disponíveis;
9. corrija falhas;
10. execute Review;
11. documente;
12. marque DONE somente após Quality Gates.

Não copie padrões de .NET/Java/Laravel automaticamente. Prefira Node.js/TypeScript idiomático.
