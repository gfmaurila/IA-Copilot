# COPILOT - Node.js AI Agents

Fluxo obrigatório:
1. Leia `CRIAR-PROJETO.md`.
2. Leia `AGENTS.md`.
3. Leia `tasks/rules/`.
4. Leia a Spec solicitada.
5. Execute Requirements -> Architect -> Tech Lead.
6. Gere `REQUIREMENTS.md`, `ARCHITECTURE_PLAN.md` e `EXECUTION_PLAN.md`.
7. Leia somente as Skills necessárias para a task atual.
8. Developer implementa incrementalmente.
9. Tester executa Prisma/migrations, testes, lint/typecheck e builds existentes.
10. Corrija todos os erros reproduzíveis.
11. Reviewer valida segurança, arquitetura e qualidade.
12. Documentation atualiza documentação.
13. Arquive a Spec somente após Quality Gates aprovados.

Não introduza padrões de C# ou Java sem necessidade.
Prefira padrões idiomáticos de Node.js/TypeScript.
