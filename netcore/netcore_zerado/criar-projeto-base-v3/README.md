- CRUD grupos

- JWT
- testes unitários
- testes de integração

- React Admin/Site

## Docker Compose

O arquivo `docker-compose.yml` começa vazio e deve ser gerado pelo Copilot
durante a execução da Spec.

A senha SQL Server segue o padrão:

```text
Gfm@d{dia}m{mes}a{ano}
```
