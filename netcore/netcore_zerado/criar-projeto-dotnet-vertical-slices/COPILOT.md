# COPILOT

Fluxo obrigatório:

1. Leia `CRIAR-PROJETO.md`.
2. Leia todas as Rules.
3. Leia a Spec.
4. Leia somente Skills necessárias.
5. Implemente por Vertical Slice.
6. Use Minimal APIs.
7. Use CQRS.
8. Preserve o Domain isolado.
9. Execute migrations.
10. Execute build.
11. Execute testes.
12. Execute build dos frontends.
13. Corrija erros.
14. Arquive a Spec somente após validação.

Não criar Controllers MVC.
Não criar Services genéricos sem necessidade.
Não mover Handlers para uma pasta global.
Não misturar slices.
