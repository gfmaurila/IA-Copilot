## Continuidade e compatibilidade multi-IA

Este é o ponto de entrada do Codex. O mesmo projeto também pode ser trabalhado por Claude Code e GitHub Copilot.

Antes de implementar:
1. leia `PROJECT.md`;
2. leia `PROJECT-STATE.md`;
3. leia `AI-WORKFLOW.md`;
4. inspecione a implementação e documentação existentes;
5. execute somente a task solicitada.

Não reinicialize o projeto, não recrie componentes existentes e não avance além do escopo atual. Preserve Vertical Slices, contratos, testes, migrations, Docker e padrões já presentes no repositório.
