# Task Protocol

## Antes
- Ler contexto obrigatório.
- Confirmar escopo, dependências e critérios de aceite.
- Identificar arquivos/áreas provavelmente afetados.

## Durante
- Fazer a menor mudança suficiente.
- Não antecipar tarefas futuras.
- Manter compatibilidade com trabalho existente.

## Depois
- Build/lint/testes aplicáveis.
- Revisar diff/alterações.
- Atualizar documentação e `PROJECT-STATE.md` quando aplicável.
- Emitir relatório padronizado PASS/PARTIAL/FAIL.
