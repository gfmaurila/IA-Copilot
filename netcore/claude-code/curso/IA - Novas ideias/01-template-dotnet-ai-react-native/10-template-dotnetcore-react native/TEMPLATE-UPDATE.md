# Atualização do template

Esta revisão atualiza o `prompts.md` para a nova direção **.NET AI
Application Platform**.

Principais alterações:

-   preserva a estrutura atual do repositório e a estratégia do Docker
    Compose;
-   substitui o posicionamento de CMS inspirado em WordPress por
    Headless Content opcional;
-   amplia Identity para IAM com users, groups, roles, permissions,
    policies, organizations e sessions;
-   adota MySQL como banco padrão;
-   exige seeds reproduzíveis nos modos Minimal, Demo e Stress;
-   adiciona LLM, RAG, Tools, Agents, Human-in-the-loop, segurança e
    observabilidade de IA;
-   exige artefatos de arquitetura, ER e UML em Draw.io logo após a
    estrutura inicial;
-   adiciona Architecture Quality Gate antes da implementação funcional;
-   mantém Modular Monolith como padrão e evita microsserviços
    prematuros.
