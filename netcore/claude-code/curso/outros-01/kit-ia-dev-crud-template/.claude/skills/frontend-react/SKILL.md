# Skill: Frontend React

Estruture por feature e responsabilidade.

Admin: dashboard, users, roles, permissions, pages, contents, menus.
Site: shell público, navegação e páginas/conteúdos publicados.
Shared: API client, contracts/models, auth state, permission helpers, design primitives e utilitários.

Permissão no React serve para UX (rota, menu, botão), nunca substitui autorização da API. Não duplique modelos manualmente quando houver estratégia de geração/contrato da API.
