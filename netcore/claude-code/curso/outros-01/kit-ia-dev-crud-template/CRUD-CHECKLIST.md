# Checklist de geração de CRUD

- [ ] Entidade/aggregate e invariantes no Domain
- [ ] Commands e Queries no Application
- [ ] Result/Notifications/Validations
- [ ] Repository contract + Unit of Work
- [ ] Persistência/migrations na Infrastructure
- [ ] Endpoints na API
- [ ] Permissions por operação
- [ ] Admin list/create/edit/delete conforme autorização
- [ ] Site público quando aplicável
- [ ] Unit tests
- [ ] Integration tests com banco TEST
- [ ] Docker atualizado se necessário
