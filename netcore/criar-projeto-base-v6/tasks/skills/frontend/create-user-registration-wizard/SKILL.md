# Skill: Create React User Registration Wizard

## Criar

Wizard em 8 etapas:

1. Personal Data
2. Documents
3. Contacts
4. Addresses
5. Account
6. Roles
7. Preferences
8. Review & Finish

## Regras

- React + TypeScript;
- React Hook Form;
- Zod por etapa;
- TanStack Query;
- Axios centralizado;
- indicador visual de progresso;
- Previous / Next / Save Draft / Finish;
- arrays dinâmicos para documentos, contatos e endereços;
- CONTACT_TYPE carregado da API;
- permitir N contatos e N contatos do mesmo tipo;
- preservar dados ao trocar de etapa;
- mapear erros do backend para campos;
- tela de revisão antes de concluir;
- redirecionar para User Details após sucesso.
