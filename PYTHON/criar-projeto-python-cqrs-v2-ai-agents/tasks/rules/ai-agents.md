# AI Agents Rules

- planejamento precede implementação;
- cada agente tem responsabilidade única;
- agentes reutilizam Rules/Skills existentes;
- não duplicar lógica já definida em Skill;
- Developer só executa tasks do plano;
- Tester e Reviewer podem devolver task ao Developer;
- nunca marcar DONE com gate falhando;
- preservar Python idiomático;
- não simular MediatR, Spring ou camadas .NET sem necessidade real;
- manter Commands/Queries explícitos, simples e testáveis.
