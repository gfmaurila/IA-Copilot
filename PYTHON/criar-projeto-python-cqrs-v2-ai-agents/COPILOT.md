# COPILOT - Python + FastAPI + CQRS + AI Agents

Fluxo obrigatório:

1. Leia `CRIAR-PROJETO.md`.
2. Leia `tasks/rules/`.
3. Leia a Spec solicitada.
4. Leia `AGENTS.md`.
5. Execute Requirements Agent e crie `tasks/generated/REQUIREMENTS.md`.
6. Execute Architect Agent e crie `tasks/generated/ARCHITECTURE_PLAN.md`.
7. Execute Tech Lead Agent e crie `tasks/generated/EXECUTION_PLAN.md`.
8. Para cada task, leia somente as Skills necessárias.
9. Developer implementa seguindo Python + FastAPI + CQRS.
10. Execute quando aplicável:
   - install dependencies
   - alembic upgrade head
   - pytest
   - Ruff
   - mypy/pyright
   - build/test frontend
11. Tester registra `TEST_REPORT.md`.
12. Reviewer registra `REVIEW_REPORT.md`.
13. Corrija falhas e repita validações.
14. Documentation Agent atualiza documentação.
15. Só então arquive a Spec e marque estado DONE.

Não copiar padrões de C# ou Java literalmente.
Usar padrões idiomáticos de Python.
