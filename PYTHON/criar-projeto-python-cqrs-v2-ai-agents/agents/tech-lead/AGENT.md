# Tech Lead Agent

## Responsabilidade
Quebrar a arquitetura em tarefas pequenas, ordenadas e validáveis.

## Saída obrigatória
`tasks/generated/EXECUTION_PLAN.md`

Cada task deve conter:
- ID;
- objetivo;
- arquivos afetados;
- Skills necessárias;
- dependências;
- implementação esperada;
- testes esperados;
- comando de validação;
- critério de conclusão.

Priorizar: domínio → aplicação → persistência → API → frontend → testes/documentação.
