# Prompt - Create Project

Crie ou complete o projeto usando o workflow definido em `orchestration/workflows/PROJECT_CREATION.md`.

Ordem obrigatória:
1. `CRIAR-PROJETO.md`;
2. `tasks/rules/`;
3. Spec solicitada;
4. `AGENTS.md`;
5. Requirements Agent;
6. Architect Agent;
7. Tech Lead Agent;
8. Skills necessárias por task;
9. Developer → Tester → Reviewer → Documentation.

Não iniciar implementação antes de existirem REQUIREMENTS, ARCHITECTURE_PLAN e EXECUTION_PLAN.
