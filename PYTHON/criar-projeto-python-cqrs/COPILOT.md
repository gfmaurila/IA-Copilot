# COPILOT

Fluxo obrigatório:

1. Leia `CRIAR-PROJETO.md`.
2. Leia `tasks/rules/`.
3. Leia a Spec solicitada.
4. Leia somente as Skills necessárias.
5. Implemente seguindo Python + FastAPI + CQRS.
6. Execute:
   - install dependencies
   - alembic upgrade head
   - pytest
   - lint/type check quando configurados
   - build frontend
7. Corrija erros.
8. Só então arquive a Spec.

Não copiar padrões de C# literalmente.

Usar padrões idiomáticos de Python.
