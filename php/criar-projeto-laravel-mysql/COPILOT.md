# COPILOT

Fluxo obrigatório:

1. Leia `CRIAR-PROJETO.md`.
2. Leia `tasks/rules/`.
3. Leia a Spec solicitada.
4. Leia somente as Skills necessárias.
5. Implemente seguindo convenções Laravel.
6. Execute:
   - composer install quando necessário
   - php artisan migrate
   - php artisan test
   - build do frontend
7. Corrija erros.
8. Só então arquive a Spec.

Não introduza Repository Pattern, CQRS ou DDD formal sem a Spec exigir.

Prefira recursos nativos Laravel.
