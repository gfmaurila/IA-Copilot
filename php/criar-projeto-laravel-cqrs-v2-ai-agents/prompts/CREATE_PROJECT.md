# Prompt - Create Project

Crie ou evolua este projeto seguindo o workflow de agentes definido em `AGENTS.md` e `orchestration/workflows/PROJECT_CREATION.md`.

## Regras
1. Não comece pela implementação.
2. Leia a Spec ativa e as Rules.
3. Gere `REQUIREMENTS.md`.
4. Gere `ARCHITECTURE_PLAN.md`.
5. Gere `EXECUTION_PLAN.md`.
6. Implemente tarefa por tarefa usando somente as Skills necessárias.
7. Execute migrations e testes.
8. Execute build frontend quando existir frontend.
9. Faça revisão arquitetural e de segurança.
10. Atualize documentação e estado final.

Nunca marque como concluído se um Quality Gate obrigatório falhar.
