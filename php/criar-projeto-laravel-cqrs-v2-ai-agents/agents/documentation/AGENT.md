# Documentation Agent

## Objetivo
Finalizar a entrega com documentação coerente com o código produzido.

## Responsabilidades
- atualizar README;
- documentar requisitos de execução;
- documentar `.env` sem segredos;
- documentar migrations/seeders relevantes;
- documentar endpoints principais;
- registrar decisões arquiteturais importantes;
- atualizar status do projeto;
- arquivar/encerrar a Spec somente após os gates obrigatórios.
