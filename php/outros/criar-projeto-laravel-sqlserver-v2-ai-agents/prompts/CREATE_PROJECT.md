# Prompt - Create Project

Crie ou evolua este projeto seguindo `AGENTS.md` e `orchestration/workflows/PROJECT_CREATION.md`.

## Regras
1. Não comece pela implementação.
2. Leia a Spec ativa e as Rules.
3. Gere `tasks/generated/REQUIREMENTS.md`.
4. Gere `tasks/generated/ARCHITECTURE_PLAN.md`.
5. Gere `tasks/generated/EXECUTION_PLAN.md`.
6. Implemente tarefa por tarefa usando somente as Skills necessárias.
7. Preserve convenções Laravel e SQL Server.
8. Execute migrations em banco adequado e separado para testes.
9. Execute testes backend.
10. Execute build frontend quando existir frontend.
11. Faça revisão arquitetural, SQL Server e de segurança.
12. Atualize documentação e estado final.

Nunca marque como concluído se um Quality Gate obrigatório falhar.
