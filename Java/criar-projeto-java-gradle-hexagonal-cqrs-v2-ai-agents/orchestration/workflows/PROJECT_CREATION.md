# Workflow — Project Creation

1. Ler `CRIAR-PROJETO.md`, rules, skills e Spec ativa.
2. Requirements Agent gera `REQUIREMENTS.md`.
3. Executar GATE-01.
4. Architect Agent gera `ARCHITECTURE_PLAN.md`.
5. Executar GATE-02.
6. Tech Lead gera `EXECUTION_PLAN.md`.
7. Developer executa tasks sequencialmente.
8. Validar persistence/build.
9. Tester executa testes e gera relatório.
10. Reviewer executa revisão arquitetural e de segurança.
11. Falha -> Developer corrige -> repetir gates afetados.
12. Documentation Agent atualiza documentação.
13. Executar GATE-08 e marcar DONE.
