# Regra — AI Agents

- Agentes coordenam Skills; não duplicam regras técnicas.
- Planejamento é obrigatório antes de implementação.
- Uma task por vez.
- Alterações devem ter critério de aceite e evidência.
- Tester e Reviewer podem devolver task ao Developer.
- Arquitetura Hexagonal tem precedência sobre conveniência de framework.
- Domain puro é requisito bloqueante.
- Não concluir com build/testes/gates falhando.
