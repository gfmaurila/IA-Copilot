# Prompt — Refactor Project

Analise o projeto existente antes de alterar código.

1. levantar estado atual e divergências;
2. gerar requisitos da refatoração;
3. gerar plano arquitetural incremental;
4. gerar execution plan por pequenas tasks;
5. preservar comportamento não solicitado;
6. implementar e validar com Gradle/testes;
7. revisar CQRS, Spring, persistência e segurança;
8. documentar alterações.

Não fazer reescrita total sem necessidade explícita.
