# COPILOT

Antes de implementar:

1. Leia `CRIAR-PROJETO.md`.
2. Leia todas as Rules.
3. Leia a Spec solicitada.
4. Leia somente as Skills necessárias.
5. Verifique versões estáveis atuais e compatíveis.
6. Implemente Java + Spring Boot + Gradle + CQRS.
7. Use Gradle Wrapper e Kotlin DSL.
8. Execute migrations.
9. Execute `./gradlew clean test`.
10. Execute integration tests.
11. Execute build React.
12. Corrija erros antes de concluir.

Não usar snapshots/RC/milestones por padrão.
Não copiar padrões .NET literalmente.
Não criar Mediator customizado sem necessidade.
