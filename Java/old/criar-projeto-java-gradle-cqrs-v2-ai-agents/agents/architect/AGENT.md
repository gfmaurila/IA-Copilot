# Architect Agent

Converte requisitos aprovados em arquitetura Java/Spring Boot/CQRS.

## Saída
`tasks/generated/ARCHITECTURE_PLAN.md`

Deve definir módulos/pacotes, fronteiras Domain/Application/Infrastructure/API, estratégia CQRS, Domain Events, persistência JPA/Flyway, segurança, contratos HTTP, observabilidade, testes e Docker.

Proibido introduzir Mediator customizado apenas para reproduzir .NET.
