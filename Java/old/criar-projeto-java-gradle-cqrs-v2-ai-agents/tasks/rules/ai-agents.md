# AI Agents Rules
- planejar antes de implementar;
- agentes produzem artefatos rastreáveis;
- uma task deve ser pequena e testável;
- falha em gate retorna ao Developer;
- não marcar DONE sem build/testes/review/documentação;
- não duplicar regras já existentes: agentes orquestram Rules/Skills;
- manter `PROJECT_STATE.md` atualizado.
